# أسماء خالدة – موقع البحث عن أسماء الشهداء

موقع ثابت (HTML/CSS/JS) بلا خادم، من إعداد IEEE Student Branch USTO.

## الملفات
- `index.html` — الصفحة الرئيسية
- `style.css` — التصميم (ألوان العلم الوطني)
- `app.js` — منطق البحث بالاسم الأول وبالحرف الأول (عربي/فرنسي)
- `data.js` — **قاعدة بيانات الأسماء** (عدّلها لإضافة أسماء أو تصحيحها)
- `assets/` — الشعار وأيقونة العلم
- `.nojekyll` — يمنع GitHub Pages من معالجة الملفات

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub (مثلًا `chouhada`) واجعله Public.
2. ارفع كل محتويات هذا المجلد (بما فيها مجلد `assets` وملف `.nojekyll`) إلى الفرع `main`.
3. من **Settings → Pages**: اختر `Deploy from a branch`، الفرع `main`، المجلد `/ (root)`، ثم Save.
4. بعد دقيقة أو دقيقتين يعمل الموقع على: `https://USERNAME.github.io/REPO/`

## إضافة اسم جديد
في `data.js` أضف كائنًا بالشكل:
```js
{"fa":"مصطفى","la":"بن بولعيد","fl":"Mostefa","ll":"Ben Boulaïd","alt":["Mustapha"],"y":"1917 – 1956","bio":"نبذة قصيرة","s":0}
```
- `fa`/`fl`: الاسم الأول بالعربية/الفرنسية، `la`/`ll`: اللقب.
- `alt`: كتابات بديلة للاسم الأول (لتطابق البحث).
- `s`: ضع `1` للطالب/الطالبة لتظهر شارة «طالب/ة».
